#### 结果对比:

| 方法 | 权重特性 | 梯度范数 | 稀疏性 |
|------|---------|---------|--------|
| **softmax** | 平滑分布 | 89.33 | 无 (所有权重>0) |
| **gumbel_softmax** | 随机采样 | 93.69 | 低 (训练时探索) |
| **sparsemax** | 稀疏化 | 722.54 | 高 (多个权重=0) |
| **entmax15** | 更稀疏 | 634.14 | 极高 (更多权重=0) |

**观察**:
- 所有方法权重和均为 1.0 (误差 < 1e-4)
- sparsemax 和 entmax15 产生稀疏权重，有利于公式选择
- sparsemax/entmax15 梯度范数更大，因为稀疏化导致梯度集中
